# yusuf-gadelrab.github.io/portfolio

Personal research and writing site for Yusuf Gadelrab — San José State University computer science student, CS tutor, and student researcher.

**Live:** https://yusuf-gadelrab.github.io/portfolio/

## Contents

- `index.html` — home
- `research/` — summary of the ACM SIGCSE TS 2026 poster "Exploring Bilingual Coding for Inclusive Computer Science Learning" (DOI [10.1145/3770761.3777339](https://doi.org/10.1145/3770761.3777339))
- `intakekit/` — IntakeKit, a local-first message-to-structured-data parsing approach
- `writing/` — technical articles on freight message parsing, local language models, and bilingual CS education
- `about/` — background and contact

## Stack

Hand-written static HTML with inline CSS. No build step, no dependencies, no JavaScript. Every page ships one HTML file.

## SEO

Per-page canonical URLs, Open Graph and Twitter card metadata, JSON-LD structured data (`Person`, `ScholarlyArticle`, `SoftwareSourceCode`), `sitemap.xml`, and `robots.txt`. All internal links are relative so the site works at any base path.

## Deployment

GitHub Pages serves the `main` branch from the repository root. `.nojekyll` disables Jekyll processing.
